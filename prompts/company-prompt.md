# Company Assessment Prompt

Copy and paste this into Claude Code to start a company-level (strategic) AI adoption assessment:

```
/deep-interview
```

Then say:

```
Run a company-level assessment for [Company Name] — a [sector] [company size]. They want to understand their AI adoption readiness and build an AI agent portfolio strategy.
```

## What to provide

When prompted for basic facts, have these ready:

- **Company name and website**
- **Sector** (e.g., FinTech, Healthcare, SaaS, Manufacturing)
- **Company size** (e.g., 50 employees, 500 employees, 5,000 employees)
- **Primary motivation** (e.g., reduce costs, compete with AI-native competitors, improve customer experience)
- **Interview depth** (quick / standard / deep)

## What you get

- AI Adoption Maturity assessment (5-level model)
- Portfolio scan with tier recommendations
- Strategic roadmap with build/buy/hybrid decisions
- HTML presentation for client meetings

## Example seed

```
Cut costs and improve competitive positioning | [Company Name] is a [sector] company with [X] employees exploring AI adoption | [Company Name] ([sector], [size])
```
